# Phoenix Creator Bench — Brand Transition

## Public product name
**Phoenix Creator Bench**

This replaces the public-facing **Phoenix Creator Studio** working name while preserving the SagaArchitect repository lineage and existing runtime identifiers.

## Product promise
A unified production workbench for story canon, writing, characters, timelines, images, covers, comics, storyboards, video/short-form planning, media assets, and export pipelines.

## Icon master
- Keep the Phoenix identity but simplify it to a geometric wing pair surrounding a central creator spark/tool point.
- The center must read as creation, not a generic bird-logo badge.
- No detailed feather illustration at app-icon scale.
- Optional subtle layered-panel motif may reference images/video/pages without turning into a collage.

## Splash master
- Phoenix mark assembles from separate creative-media panels: page, image frame, storyboard tile, timeline strip, and playhead.
- Panels converge into the Phoenix mark.
- Wordmark: **Phoenix Creator Bench**.
- Secondary line retained: **Write it. Build it. Bring it to life.**

## Required production exports
- 1024×1024 app/store icon master.
- 512, 192, 64, 32 web/PWA exports.
- 2732×2732 launch/splash master.
- 1920×1080 hero/marketing master.
- Transparent SVG source mark.

## Compatibility rule
Do not rename the npm package `phoenix-creator-studio`, `com.bobbysworld.phoenixcreatorstudio`, `phoenix_*` persisted keys, database names, migrations, staging environment names, repo URLs, or release evidence identifiers as part of this display-brand PR. Those require a separately qualified migration.
