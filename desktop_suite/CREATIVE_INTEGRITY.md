# Creative desktop integrity candidate
This desktop edition remains a local-records workspace, not the integrated structured canon and storyboard engine. Existing store path and record shape are preserved. Malformed/invalid stores fail closed; saves use an exclusive lock, unique IDs, fsynced temporary file and atomic replacement. Existing stale locks require reviewed recovery, never automatic deletion. UI renders authored records as text and retains unsaved inputs on failure. No migration, provider calls, installed app replacement or publication. Full engine integration, backup/recovery UX, browser interactions, cross-platform filesystem and crash durability qualification remain open. These tests use synthetic records in isolated temporary directories.
